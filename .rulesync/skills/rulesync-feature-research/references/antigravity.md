# Google Antigravity Map

Antigravity 2.0 ships as three products over one shared `.agents/` customization
tree: the **IDE** (`antigravity-ide`), the **CLI** (`antigravity-cli`, `agy`),
and bundled **plugins** (`antigravity-plugin`). Most project surfaces are shared
between the IDE and the CLI; globally they diverge across the shared
`~/.gemini/config/`, the IDE's `~/.gemini/antigravity/`, and the CLI's
`~/.gemini/antigravity-cli/`, with global rules sitting outside all three at
`~/.gemini/GEMINI.md`. Check the per-surface rows before assuming which tree a
global file lands in.

## Open Questions

- **CLI permissions have no project scope in Rulesync**, although the CLI has merged project-level permissions since v1.0.5. The committable file would be the workspace `.antigravity/settings.json` the IDE already writes.
- **Docs restructure (observed 2026-09-26).** The surface-specific pages `/docs/rules-workflows`, `/docs/cli/plugins`, `/docs/cli/settings` and `/docs/cli/permissions` dropped out of the sitemap in favour of the surface-tabbed `/docs/rules`, `/docs/plugins`, `/docs/settings` and `/docs/permissions`. Antigravity 2.17.0 also mentions repository customization settings in `/.gemini/config.json`, which no docs page defines yet.

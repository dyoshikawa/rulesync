# Google Antigravity Map

Antigravity 2.0 ships as three products over one shared `.agents/` customization
tree: the **IDE** (`antigravity-ide`), the **CLI** (`antigravity-cli`, `agy`),
and bundled **plugins** (`antigravity-plugin`). Most project surfaces are shared
between the IDE and the CLI; globally they diverge across the shared
`~/.gemini/config/`, the IDE's `~/.gemini/antigravity/`, and the CLI's
`~/.gemini/antigravity-cli/`, with global rules sitting outside all three at
`~/.gemini/GEMINI.md`. Check the per-surface rows before assuming which tree a
global file lands in.

## Official Docs

| Feature       | Official docs                                                                                    | Upstream surface                                                                                                                                                                                                                                                                                                                                                     |
| ------------- | ------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| index         | `https://antigravity.google/docs/getting-started`                                                | Antigravity 2.0, CLI, IDE, and SDK doc trees under one nav (`/docs` redirects here)                                                                                                                                                                                                                                                                                  |
| `rules`       | `https://antigravity.google/docs/rules-workflows`                                                | Workspace rules in `.agents/rules/` (legacy `.agent/rules` still read), global `~/.gemini/GEMINI.md`; per-rule activation is Manual / Always On / Model Decision / Glob; 12,000-character limit per file                                                                                                                                                             |
| `ignore`      | No dedicated upstream ignore surface in map                                                      | No ignore page in the Antigravity docs tree; the CLI inherits the Gemini-CLI lineage's project-root `.geminiignore`, which is what Rulesync emits — re-verify before widening                                                                                                                                                                                        |
| `mcp`         | `https://antigravity.google/docs/mcp`                                                            | `mcp_config.json`: global `~/.gemini/config/mcp_config.json`, workspace `.agents/mcp_config.json`; IDE also installs through its MCP Store, CLI through an interactive MCP manager                                                                                                                                                                                   |
| `commands`    | `https://antigravity.google/docs/ide/workflows`                                                  | Workflows: markdown files invoked as `/workflow-name`, authored per workspace or globally through the Customizations panel; 12,000-character limit per file (the page describes the panel, not the on-disk path)                                                                                                                                                     |
| `subagents`   | `https://antigravity.google/docs/subagents`                                                      | Custom subagents as `.md` + YAML frontmatter: workspace `.agents/agents/<name>.md` or `.agents/agents/<name>/agent.md`, global `~/.gemini/config/agents/`, plugin `plugins/<name>/agents/`                                                                                                                                                                           |
| `skills`      | `https://antigravity.google/docs/skills`                                                         | Agent Skills (`SKILL.md` per folder): workspace `.agents/skills/<skill>/`, global `~/.gemini/config/skills/<skill>/` (legacy `.agent/skills` still read)                                                                                                                                                                                                             |
| `hooks`       | `https://antigravity.google/docs/hooks`                                                          | `hooks.json` in the customization dir (`.agents/` or `~/.gemini/config/`), keyed by hook-group name then PascalCase event; `PreToolUse`/`PostToolUse` values wrap `hooks[]` (`type`, `command`, `timeout`) in a `matcher` group, while `PreInvocation`/`PostInvocation`/`Stop` hold the handler list directly and ignore any matcher; a group takes `enabled: false` |
| `permissions` | `https://antigravity.google/docs/permissions`, `https://antigravity.google/docs/cli/permissions` | Three access lists — Allow / Ask / Deny — of `action(target)` entries over `read_file`, `write_file`, `read_url`, `execute_url`, `command`, `unsandboxed`, `mcp`, evaluated `Deny > Ask > Allow`; write implies read. The `permissions.allow`/`ask`/`deny` JSON object shape and `~/.gemini/antigravity-cli/settings.json` are on the CLI page, not the main one     |

## Client Anchors

Common adapter paths: `rulesync-source-map.md`.

| Surface       | Anchor                                                                                                                                                                                                                                                                                                                               |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| paths         | `antigravity-paths.ts` (shared `.agents/` tree and `~/.gemini/config/`), `antigravity-ide-paths.ts`, `antigravity-cli-paths.ts` (`~/.gemini/antigravity-cli/`)                                                                                                                                                                       |
| `rules`       | Root rule as the cross-tool `AGENTS.md` and non-root rules under `.agents/rules/` in `antigravity-ide-rule.ts` / `antigravity-cli-rule.ts` / `antigravity-plugin-rule.ts`; global `~/.gemini/GEMINI.md` shared by the IDE and the CLI. `AGENTS.md` is a Gemini-lineage discovery-order choice, not a documented Antigravity filename |
| `ignore`      | `.geminiignore` emission in `antigravity-cli-ignore.ts` (CLI target only)                                                                                                                                                                                                                                                            |
| `mcp`         | `antigravity-ide-mcp.ts` / `antigravity-cli-mcp.ts` / `antigravity-plugin-mcp.ts` over the shared conversion in `antigravity-mcp.ts`; global file is shared, so enabling both targets writes it once                                                                                                                                 |
| `commands`    | Project `.agents/workflows/` in `antigravity-shared-command.ts`; global splits — IDE `~/.gemini/antigravity/global_workflows/`, CLI `~/.gemini/antigravity-cli/global_workflows/`                                                                                                                                                    |
| `subagents`   | `antigravity-shared-subagent.ts` plus the three target wrappers; project `.agents/agents/`, global `~/.gemini/config/agents/`, plugin `agents/`                                                                                                                                                                                      |
| `skills`      | `antigravity-shared-skill.ts` plus the three target wrappers (including `antigravity-plugin-skill.ts`); project `.agents/skills/`, global splits — IDE `~/.gemini/config/skills/`, CLI `~/.gemini/antigravity-cli/skills/`                                                                                                           |
| `hooks`       | `antigravity-hooks.ts` (project `.agents/hooks.json`, global `~/.gemini/config/hooks.json`, shared by both targets) and `antigravity-plugin-hooks.ts`; five canonical events map onto the PascalCase set — see `ANTIGRAVITY_HOOK_EVENTS`                                                                                             |
| `permissions` | `antigravity-ide-permissions.ts` writes the workspace `.antigravity/settings.json`; `antigravity-cli-permissions.ts` is global-only (`~/.gemini/antigravity-cli/settings.json`)                                                                                                                                                      |
